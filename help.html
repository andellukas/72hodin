72 hodin – offline poradce

Nápověda pro uživatele

Jak to používat

  • Do vyhledávání piš normálně česky – můžeš i bez diakritiky a s překlepy (např. sirema, eletrika).
  • V režimu PANIKA uvidíš krátké okamžité kroky (PANIKA ULTRA + TEĎ HNED).
  • V režimu PLNO uvidíš detailní plán (Další hodiny / 72 hodin / Co nedělat / Kdy volat pomoc).
  • Funguje to i offline – stačí jednou otevřít, nechat načíst a pak je to připravené.

Jak nainstalovat (PWA)

  • Android (Chrome): menu (⋮) → Přidat na plochu / Nainstalovat aplikaci
  • iPhone (Safari): Sdílet → Přidat na plochu
  • Desktop (Chrome/Edge): ikona instalace v adresním řádku → Install

Offline test

  • Otevři stránku offline.html a spusť self-test.
  • Když je vše ok, uvidíš “CACHE OK” a “FETCH OK offline”.

Bezpečnost

  • Nešiř neověřené zprávy. Drž se pokynů obce/IZS.
  • Při ohrožení života volej 155 / 112. Požár 150.
